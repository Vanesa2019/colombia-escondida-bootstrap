# Colombia Escondida

Landing page desarrollada para la actividad de Bootstrap de la asignatura Programación Web.

El proyecto presenta diferentes destinos de Colombia utilizando componentes y clases de Bootstrap 5.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap CDN

---

## Componentes de Bootstrap utilizados

El proyecto utiliza los siguientes componentes:

- Navbar responsivo
- Carousel
- Sistema de grilla (Grid)
- Cards
- Modal
- Formularios
